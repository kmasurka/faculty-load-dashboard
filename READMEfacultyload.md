# Faculty Course Load Dashboard

Open the live page, load the faculty list (`faculty_dept.xlsx`) and one or more REG Cap Status exports, then click **Generate Dashboard**.

- Runs entirely in the browser. The Excel files are read on your computer and are never uploaded.
- Name REG Cap files with the term (e.g. `REG_Cap_Spring_2027.xlsx`) so the semester and year fill in automatically.
- Each tab has a Print Report button. Use "Save as PDF" in the print dialog.

**Updating:** replace `index.html` with a new version. The page updates within a minute or two.

Version 2.0 (browser edition), October 13, 2026. Load calculations are identical to Version 1.0 (`app.py`).
